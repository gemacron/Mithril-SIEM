🛡️ CÓMO CONECTAR UN PROXY NGINX A MITHRIL (PUERTO 9900)

Agente persistente con systemd, compatible con Ubuntu/Debian y Rocky Linux/AlmaLinux/RHEL. Mitigación en Kernel con ipset o recarga suave de Nginx.

Ubuntu 20/22/24 Rocky Linux 8/9 Systemd Persistente Zero-Pip Deps
💡 Recomendado: El script install_agent.sh detecta automáticamente si estás en Ubuntu o Rocky Linux, instala los paquetes requeridos, crea el servicio mithril-bouncer.service en systemd y lo deja activo y persistente tras reinicios.
Paso 1: Clonar repositorio oficial en el proxy 
git clone https://github.com/gemacron/Mithril-SIEM.git /tmp/Mithril-SIEM
Paso 2: Ejecutar el instalador universal (Modo Interactivo) 
sudo bash /tmp/Mithril-SIEM/agent/install_agent.sh

* Te solicitará la URL del SIEM (http://{{ host_ip }}:9900) y el NODE_API_KEY que obtienes al crear el nodo arriba.

Alternativa: Instalación en una sola línea (Automatizada / Ansible) 
sudo bash /tmp/Mithril-SIEM/agent/install_agent.sh "http://{{ host_ip }}:9900" "TU_NODE_API_KEY" "ipset" "15"

Comandos específicos para Ubuntu 20.04 / 22.04 / 24.04 LTS y Debian 11 / 12:

1. Dependencias del sistema (apt) 
sudo apt-get update
sudo apt-get install -y python3 ipset iptables curl git
2. Archivo de servicio Systemd (/etc/systemd/system/mithril-bouncer.service) 
sudo cat <<'EOF' > /etc/systemd/system/mithril-bouncer.service
[Unit]
Description=Mithril SIEM Bouncer Agent
After=network.target nginx.service

[Service]
Type=simple
User=root
Environment="MITHRIL_URL=http://{{ host_ip }}:9900"
Environment="NODE_API_KEY=TU_NODE_API_KEY"
Environment="BLOCK_METHOD=ipset"
Environment="SYNC_INTERVAL=15"
Environment="NGINX_BLOCK_FILE=/etc/nginx/conf.d/mithril_blocklist.conf"
ExecStart=/usr/bin/python3 /opt/mithril-agent/mithril_bouncer.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF
3. Iniciar y habilitar servicio persistente 
sudo systemctl daemon-reload
sudo systemctl enable --now mithril-bouncer.service

Comandos específicos para Rocky Linux 8 / 9, AlmaLinux, RHEL y CentOS Stream:

1. Dependencias del sistema (dnf) 
sudo dnf install -y python3 ipset iptables curl git
2. Configuración SELinux (si aplica) 
sudo setsebool -P httpd_can_network_connect 1
3. Iniciar y habilitar servicio persistente 
sudo systemctl daemon-reload
sudo systemctl enable --now mithril-bouncer.service

Configuración de Nginx para enviar logs en tiempo real vía Syslog UDP (puerto 5140) e incluir la lista de bloqueo:

1. Formato JSON (pegar dentro de 'http { ... }' en /etc/nginx/nginx.conf) 
log_format mithril_json escape=json '{'
    '"client_ip":"$remote_addr",'
    '"time_local":"$time_iso8601",'
    '"http_method":"$request_method",'
    '"uri":"$uri",'
    '"query_params":"$args",'
    '"status_code":$status,'
    '"bytes_sent":$body_bytes_sent,'
    '"latency_ms":$request_time,'
    '"user_agent":"$http_user_agent",'
    '"referer":"$http_referer"'
'};
2. Directivas en el VirtualHost (dentro de server { ... }) 
# 1. Inclusión de lista negra administrada dinámicamente por Mithril
include /etc/nginx/conf.d/mithril_blocklist.conf;

# 2. Envío directo al SIEM por Syslog UDP en tiempo real
access_log syslog:server={{ host_ip }}:5140,facility=local7,tag=nginx mithril_json;
3. Validar sintaxis y recargar Nginx sin caídas 
sudo nginx -t && sudo systemctl reload nginx

Comandos de diagnóstico para monitorear el agente y las reglas de bloqueo en tu proxy:

Estado del Servicio Systemd
sudo systemctl status mithril-bouncer
Registros de Telemetría en Vivo
sudo journalctl -u mithril-bouncer -f
Ver IPs Bloqueadas en Kernel (ipset)
sudo ipset list mithril_blacklist
Ver Archivo de Bloqueo Nginx
cat /etc/nginx/conf.d/mithril_blocklist.conf
